## 🔧 Getting Started

### 1. View the Web Application
```bash
cd /artifacts/mockup-sandbox
pnpm install
pnpm dev
# Visit http://localhost:5173
```

Navigate tabs to see:
- 📊 Dashboard (metrics, activities, services)
- 📝 Patient Form (registration)
- 📋 Patients Directory (data table)
- 🔔 Alerts (notifications)

### 2. View the Mobile Application
```bash
cd /artifacts/digihealth
pnpm install
pnpm dev
# Scan QR or use emulator
```

### 3. Explore the Components
See examples in [UI-ENHANCEMENT-GUIDE.md](./UI-ENHANCEMENT-GUIDE.md)

### 4. Customize for Your Needs
Follow [UI-ENHANCEMENT-GUIDE.md](./UI-ENHANCEMENT-GUIDE.md) - Customization section
